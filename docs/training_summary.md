# 实训总结报告

## 一、项目研发流程

通过本次运动图像分类项目，我完整经历了从需求分析、技术选型到模型训练与部署的全流程。项目选用 PyTorch 框架和 EfficientNet-B0（5.3M 参数）对 100 类运动图片进行分类训练，最终达到 98.40% 的测试准确率。在架构层面，我从最初的 Gradio 单体应用出发，逐步将其迁移为 React + FastAPI 的前后端分离架构，体会到了工程化拆分对项目可维护性和扩展性的重要意义。

## 二、代码调试能力

在训练过程中，我遇到了一系列实际问题并逐一排查解决。例如，初始学习率 1e-3 导致训练损失震荡，将其降至 1e-4 后配合 StepLR 调度策略使模型稳定收敛；在增大 batch size 时出现 GPU 显存溢出（OOM），通过调整输入分辨率和分批次加载予以解决；在 Windows 环境下 DataLoader 的多进程配置引发 BrokenPipeError，经排查后将 num_workers 设为 0 并优化了数据加载逻辑。这些调试经历显著提升了我的问题定位和排错能力。

## 三、文档编写能力

项目期间我编写了完整的技术文档体系，涵盖技术原理说明、软件体系结构文档、答辩准备材料、项目工作流程、技术报告以及架构可视化文档共 6 份。通过撰写这些文档，我学会了如何将技术实现过程以结构化、条理清晰的方式表达出来，使文档既能服务于团队协作，也能作为项目交付的重要成果。此外，我利用 Python 脚本自动生成了架构图，将可视化手段融入文档编写流程，提高了文档的直观性和专业度。
